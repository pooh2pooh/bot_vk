## Описание
Бот поддержки для чата Manjaro Linux русскоязычное сообщество.
### Вот, что умеет этот бот
* Обнаружать опасные команды вроде `rm -rf /` и отвечать на них предупреждением, даже если сообщение отредактировали
* Напоминать участникам чата о вежливости и терпимости по достижению N сообщений
* Слушать RSS фид официального проекта, новости, блог, обновления, релизы

Пока, это всё :)
